# Sóller Ara

Versió inicial del projecte **Sóller Ara**, un agregador local d'informació pública pensat inicialment per a Sóller.

## Versió

v0.1

## Objectius de la primera versió

- Interfície moderna i adaptable a mòbil.
- Català com a idioma predeterminat.
- Castellà i anglès disponibles.
- Selector d'idioma persistent al dispositiu.
- Categories bàsiques.
- Cercador local.
- Targetes de publicació preparades per mostrar font i enllaç original.
- Base preparada per evolucionar cap a una PWA.

## Estat actual

Aquesta versió utilitza dades de demostració. Encara no hi ha connexions automàtiques amb fonts reals.

## Estructura

- `index.html`: estructura principal.
- `styles.css`: disseny visual.
- `app.js`: traduccions, filtres, cerca i dades de demostració.
- `manifest.webmanifest`: configuració inicial PWA.

## Cost

La v0.1 no requereix cap servei de pagament.
